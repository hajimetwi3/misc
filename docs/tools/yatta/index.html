項目を編集

「他」は時刻に縛られないチェック用（ストレッチ・日記など、今日やったかだけ気にする項目に）

データの保存・読み込み

エクスポートされるのは項目名と時間帯の設定のみです。
チェック履歴は含まれません。

項目とチェック履歴をすべて削除し、初期状態に戻します。

注意事項
  • このアプリはサーバーにデータを送信しません。すべてのデータはお使いのブラウザ内にのみ保存されます。
  • チェック履歴は直近3日分のみ保持されます。それ以前の履歴は自動的に削除されます。
  • ブラウザの設定で「Cookieとサイトデータ」を削除すると、保存データも消去されます。
  • 長期間アクセスしない場合、ブラウザがデータを自動削除することがあります。
  • 端末やブラウザが異なると、データは共有されません。項目設定はエクスポート・インポートで移行できます。
  • 登録できる項目は最大100個までです。
  • インポートには、このアプリからエクスポートしたJSONファイルのみを使用してください。それ以外のファイルを読み込むと正しく動作しない場合があります。
