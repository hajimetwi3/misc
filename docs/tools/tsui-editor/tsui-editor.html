About

Tsui Editor はブラウザで動くローカルファイルエディタです。File System Access API でフォルダまるごと読み書き、タブ・ツリーで操作。ログイン不要、インストール不要、データの外部送信なし。
— 詳細 —

Privacy

ファイルや入力内容は、本アプリ本体から外部送信されません。CSP の connect-src 'none' により、fetch 等のネットワーク送信はブラウザレベルで禁止されています。DevTools の Network タブで確認いただけます。

ファイルや入力内容自体は localStorage や IndexedDB に保存しません。これらは File System Access API 経由で選択されたフォルダの中にのみ存在します。なお、UI 設定（フォントサイズ・折り返し・Sys Font・Theme・Lang・サイドバー幅）は localStorage に、前回フォルダへの再アクセス用ハンドルは IndexedDB に保存しています。

本アプリ本体には計測機能は一切含まれていません（上記 CSP により外部送信が禁止されているため）。

一方、作者プロフィールや Tsui series のランディングページ等の情報ページでは、訪問数の把握に Cloudflare Web Analytics を利用しています（Cookie なし / フィンガープリントなし / クロスサイトトラッキングなし）。

なお、別途プラットフォーム側（配信元サーバや中継事業者等）で計測・記録されている可能性はあります。

注意

File System API の仕様上、選択したフォルダ配下への読み書き・削除権限を持ちます。重要フォルダや同期フォルダではなく、専用の作業フォルダで利用することを推奨します。
